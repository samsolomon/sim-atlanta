# Radio: how the music was made

- **Coded track:** `Something Small (Demo)` is synthesized in Python (numpy/scipy) from the
  November 2026 SimCity-style sketch: piano ostinato, warm pad, flute-like lead, soft beat,
  F major, 100 BPM, with intro, A, B, a drumless bell break, a lifted A and an outro.
- **ElevenLabs Music** (`music_v2_5`, instrumental). Prompts describe instruments, mood,
  tempo and structure, and never name artists, songs, labels or games. Three later tracks
  used chunked composition plans; v2.5 honoured the instruments but mostly ignored
  "drums drop out" sections.
- **Stations** were Sam's idea (2026-11-24): flip between them like car radio in a game;
  the first one follows the scene clock.
- **Covers:** one per fictional artist, generated by a Codex agent, reviewed at 64 px.
  See `covers/README.md` for prompts and the alternates that weren't picked.
- **Player spec** (compact one-row player, crossfade, stations): `docs/ui-controls-brief.md`,
  section Radio, on the UI branch.
