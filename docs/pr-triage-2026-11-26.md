## How to read the tables

- **Budget:** High-night calls / Low geometry MB / High geometry MB / programs, as deltas. **S** = stated in the PR body, **E** = estimated from the diff, **-** = no product geometry. `?` = not stated. Almost all were measured on older mains, before #575 and #682, so re-measure in the batch. Single-call deltas are often run-to-run noise. Triangles and Low and High calls are in the JSON.
- **Mergeable:** GitHub's answer on 2026-11-26, then the files `git merge-tree` reports against current `main`. A clean text merge is not a build: run `pnpm build` on the final head.
- **Superseded:** nothing is noted where no newer work on `main` was found. Checked by building ids and file overlap with #682, #613, #686, #687, #689–#694, #696–#698, #700, #701, #704 and #705, and by how many added lines are already on `main`.
- **Sam's eye:** "if list unconfirmed" means no look is needed if the merge plan's list is real.
- **Agent:** the lane comes from handoff documents where one names the work. "Codex" is inferred from commits with no Claude co-author trailer.
