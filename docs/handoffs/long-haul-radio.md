# Long Haul radio

The Sim UI agent owns the five-preset radio and its three new recordings on `samsolomon/long-haul-radio`. Long Haul 103.9 is listener-selected. The existing four stations retain their scene-clock defaults.

Axle & Pine shares the *Sunday Shoes* sleeve across both shuffles. Nell Tiller has a separate sleeve for *Porch Light*. The MP3s and cover assets follow the exclusions in the root licence and the terms in `web/public/music/README.md`.

The [desktop picker](../log/ui/long-haul/1280.jpg), [phone picker](../log/ui/long-haul/390.jpg) and [two sleeves](../log/ui/long-haul/records.jpg) record the visual checks. The radio serves static files. A normal web rebuild and deployment publishes the new station.
