# Below-grade MARTA stations (research)

## State (2026-11-27)

Docs only, no City code. [The table and notes](../underground-stations.md) and [the JSON](../underground-stations.json) cover 20 below-grade stations (22 platform levels) and list the 18 left out. The JSON was checked for parsing, resolvable source ids, track centrelines that span each platform, and each of the 81 pipeline rail stop ids appearing once. No tests or browser checks: nothing runs this data.

## Before drawing ghost stations

- Draw platforms 183 m long. Underground OSM polygons are shorter sketches.
- Depth is unknown on 14 of 22 levels, including 6 of the 8 on the City board. Seven have a terrain estimate (track bed below nearby bare ground, `inferred`); only Peachtree Center has a published figure.
- City's tracks sit 4.2 m apart on one centreline and are not drawn below −5.5 m, so island platforms need their own track positions.
- Place platforms from the OSM geometry, not GTFS stop points, which sit up to 180 m away.

## Reproduction

The files were generated by a one-off script from an Overpass query (data as of 2026-11-28 02:55 UTC), USGS 3DEP point samples, the linked pages, and pipeline output generated 2026-11-26. The script and downloads were not committed. The JSON keeps the OSM way versions, Wikipedia revision ids and elevation sample coordinates.
