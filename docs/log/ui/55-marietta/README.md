# 55 Marietta Street, former Fulton National Bank

On the approach from Five Points the long Marietta frontage reads as two fields of horizontal windows. The taller field rises toward Forsyth, then drops back for the last few metres at the corner. At street level, four pale piers mark three deep entrance bays. The [production City view before the study](production-before.jpg) shows the single flat top that previously occupied this site.
