# Langdale Hall

Georgia State's classroom building faces the plaza with tall dark brick panels. Paired pale concrete piers frame narrow vertical stacks of windows, and three white-framed storeys run across the top. The plaza's glazed entrance sits beneath a brick panel. [Plaza approach, September 2024](https://www.google.com/maps/@?api=1&map_action=pano&viewpoint=33.75290,-84.38680&heading=320&pitch=25&fov=100)

From the Greenway, the projecting end has a different pattern. Horizontal concrete beams cross three columns of dark panels above a glazed ground floor. Its upper three storeys have windows clustered toward the middle. [Georgia State, Greenway in the Fall at Langdale Hall, 2021](https://provost.gsu.edu/files/2022/08/Greenway-in-the-Fall-at-Langdale-Hall-2021-800x533px-min.jpg)

The downtown footprint is Overture building `948a44ff-43db-4085-9b23-63a966006ca8`. Lidar places the main roof about 42 m above the 313 m NAVD88 ground datum and the central penthouse about 46–48 m above ground. The mapped height is 28.8 m. Bay widths, penthouse plan and floor heights are estimates. Both references show daylight. Night occupancy and lighting are illustrative.
