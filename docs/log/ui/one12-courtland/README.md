# One12 Courtland, 112 Courtland Street NE

The Dobbs entrance and the Courtland storefronts belong to the same apartment complex. The project engineer describes an existing eight-story building renovated alongside a new sixteen-story tower. The architect’s photographs show five angular entrance canopies on the shorter building, a ground-level residential courtyard and a separate rooftop pool deck. [J&A Engineering project description](https://jaengineering.net/project/one12-courtland/) · [Niles Bolton Associates project photographs](https://www.nilesbolton.com/one12-courtland) · [Operator’s address and amenities](https://www.one12courtland.com/amenities/)

## Footprints and lidar

[North-up plot of the returns and three footprint boundaries](lidar.webp)

Two Overture records carry the One 12 Courtland name. A third, unnamed 3.1 × 5.9 m record spans the gap between them. Measurements below come from sampling the 2018 Georgia block 2 lidar in the City coordinate frame. The street grades are based on the downtown terrain grid. | Link, `9af30d4c…` | Fifty-one returns span parts of the adjoining roofline and a cover near 344.6 m. The connecting volume follows that separate footprint. Its lower elevation and window bands are estimates. |
| Water and paving | A narrow strip without roof returns lines up with the pool in the aerial and the architect’s photography. The model approximates the pool length at 15 m. The west courtyard is a separate opening several stories below. |

The baked floor attribute for the west building is seven. The model uses the project engineer’s eight-story description and the photographed two-level base and six upper window rows. Window depth, bay spacing, garage recess, canopy projection and rooftop equipment sizes are visual estimates.
