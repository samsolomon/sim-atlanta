# Richard B. Russell Federal Building and Courthouse

The west side rises above the tracks at the former Terminal Station site. In the night rail photograph, groups of windows repeat between the pale spandrels, with a nearly solid ribbed screen around the crown. Across the block, the renovation architect’s photographs show a low, white, curved pavilion with long narrow windows and a tall glazed end. The street side and rail side share the same main tower. [Night rail photograph](https://www.flickr.com/photos/145683096@N07/52635328637/) · [Renovation architect’s exterior gallery](https://cglcompanies.com/projects/richard-b-russell-federal-building-u-s-courthouse/) · [Street approach photograph](https://commons.wikimedia.org/wiki/File:Richard_Russell_Federal_Building.jpg)
