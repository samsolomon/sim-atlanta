# 260 and 270 Peachtree Street

At Baker Street, the west side of Peachtree has two distinct office facades within the existing board. The darker southern building is the 27-story Coastal States tower. The northern building, originally built for Georgia Power, has pale masonry piers and an attached garage. The bake supplied separate building outlines but gave the office and garage at 270 a common height.
