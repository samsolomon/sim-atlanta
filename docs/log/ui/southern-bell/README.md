# Southern Bell Telephone Company Building

The National Register records the building at 51 Ivy Street. Georgia State’s 1961 photographs name the same corner under its current street name, 51 Peachtree Center Avenue NE at Auburn Avenue. The broad west front, stepped middle and narrow eastern return coincide with the baked footprint labeled AT&T. This is the downtown Southern Bell building: the earlier telephone building at 25–27 Auburn is a separate Georgia State property. [National Register nomination](https://npgallery.nps.gov/GetAsset/2fca93f7-39d2-4387-a00f-ded6fd84a1ad) · [Georgia State / AJC corner photograph](https://digitalcollections.library.gsu.edu/digital/collection/ajc/id/3356/) · [Georgia State’s 25–27 Auburn record](https://www.usg.edu/regents/assets/regents/documents/board_meetings/Board_of_Regents_May_11%2C_2021_Agenda_%28public%29_2.pdf) · [Production City before](production-before.jpg)

The 1929 design was built to six floors. Later work brought it to fourteen, and the rooftop tower was added in the 1960s. The City model follows the built silhouette. [Downtown Atlanta Contemporary Historic Resources Survey](https://ctycms.com/ga-atlanta/docs/dachrs_finalreport.pdf)

## Roof elevations against terrain

The Overture building record `c39654db-4734-4f65-a65e-8c46ff9e1fb0` gave one 78 m extrusion to a roughly 67 × 50 m main block and its narrow east extension. There are 11,516 sampled 2018 lidar returns inside the ring. Roof and ground figures below share the NAVD88 vertical datum. The model consumes only that named record. The adjacent low buildings keep their own footprints. Window spacing, relief carvings, the profile of the entrance, lattice members, small rooftop fittings, roundel artwork and emissive brightness are visual estimates.
